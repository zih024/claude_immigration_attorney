# Publication & Citation Table

**Optional.** Builds a **summary table** + **TSV** (full columns), **lead C5 picks**, **Criterion 3 side list** (press *about* the client), and a **checklist** from the document index. Tags each row for C5 vs NIW vs C3-only; uses `NEEDS VERIFICATION` instead of inventing citations.

## Install

```json
{
  "skills": ["./publication-citation-table/skill.md"]
}
```

## When to use

O-1A/EB-1A **Criterion 5** or NIW with a real publication line. Skip if there are no papers.

## Usage

```
/publication-citation-table
```

## Workflow

`document-summary-arrangement` → index → **(optional)** this skill → then narrative skills as usual.
